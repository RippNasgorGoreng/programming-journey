Informasi mengenai EduTask

EduTask v1.0

Platform Manajemen Tugas Siswa

Deskripsi

EduTask adalah aplikasi web sederhana yang dirancang untuk membantu siswa mengelola tugas-tugas sekolah mereka dengan lebih terorganisir. Aplikasi ini dibuat sebagai Proyek Akhir Semester dengan fokus pada penerapan HTML, CSS, dan JavaScript murni tanpa framework.

Fitur Utama

  • Autentikasi pengguna (Login & Registrasi)
  • Dashboard visual untuk monitoring tugas
  • CRUD (Create, Read, Update, Delete) Tugas
  • Pencarian dan filter tugas
  • Halaman statistik tugas
  • Reward game yang terbuka jika semua tugas selesai

Teknologi yang Digunakan

HTML5 CSS3 JavaScript LocalStorage

Pengembang

Dibuat oleh siswa Kelas 10 SMK untuk memenuhi tugas Proyek Akhir Semester.
